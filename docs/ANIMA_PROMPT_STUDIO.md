# Prompt Studio and Anima

Prompt Studio is available for every generation model. Build, Mix, Editor and Library share one draft. Anima artist selections are included in the offline collections; choose the Anima selection in Library, then add artists to the draft. Mix can blend the selected artists with individual weights.

Use the artist prefix checkbox only when your model expects `@` prefixes. Preview the assembled prompt before Send. The generation model, LoRA controls and inpainting state remain managed by Mooshie's existing generation workspace.

See [Prompt Studio](PROMPT_STUDIO.md) for collections, templates, local catalogs, import/export and weight conversion.
